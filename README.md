# 🏐 拚進白河商工排球隊 ─ 2027 會考作戰計畫

一頁式網站，給一位 **2026 年升國三、2027 年 5 月考會考** 的學生。
目標：**考進國立白河商工（白商），並從零基礎加入學校排球隊。**

## 這一頁在講什麼

| 區塊 | 內容 |
|---|---|
| 三個真相 | 校名正名、白商排球是「乙級校隊」不是體育班、入學門檻沒想像中高 |
| 認識白商 | 地址／電話／科別／校地，附排球場位置圖 |
| 兩條路 | 讀書線 × 練球線的雙軌路線圖 |
| 會考幾分 | 臺南區免試入學 108 分積分拆解＋三個檔位目標 |
| 練球項目 | 五大基本功＋體能菜單，每項都有可量化檢核點 |
| 9 個月表 | 2026/8 → 2027/8 逐月「讀書 + 練球」進度時間軸 |
| 一週作息 | 可直接照抄的週計畫表 |
| 現在就做 | 一週內能完成的 7 件事 |
| 資料來源 | 查證來源 + 明確標示「查不到、要自己問學校」的部分 |

## 技術

- 單一 `public/index.html`，**零外部依賴**：CSS、JavaScript、所有插圖（inline SVG）全部內嵌
- 會考倒數計時鎖定 `2027-05-15T08:20:00+08:00`
- 支援手機 / 平板 / 桌機，尊重 `prefers-reduced-motion`
- 部署：Cloudflare Workers Static Assets

## 本機預覽

```bash
npx wrangler dev
```

## 部署

```bash
npx wrangler deploy
```

## 重要提醒

網站內容為 **2026 年 8 月** 依公開資料整理，**不是官方文件**。
